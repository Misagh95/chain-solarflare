## 📊 Overview

SolarFlare is a decentralized marketplace for renewable energy trading and clean energy certificates.

### Key Features
- ☀️ 10-second block time
- ⚡ P2P energy trading
- 📊 Smart meter integration
- 🔋 Battery storage tracking
- 🐍 Built with Python
